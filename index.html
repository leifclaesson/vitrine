What’s in the case

A display case for a single page.

Vitrine (French for a glass display case) replaces the old chrome.exe --app= kiosk hack — whose taskbar button was the whole problem. In its place: a purpose-built WebView2 host that frames one URL and gets out of the way. No address bar, no tabs, no trim. Just the exhibit.

I

No taskbar button

A frameless WebView2 window, one URL, edge to edge. skip_taskbar + no decorations — the tray icon is the only chrome on the whole thing.

II

One case, one page

A named mutex keeps one window per config. Relaunch the same one and it steps forward instead of duplicating — and pulls a kiosk stranded off a vanished monitor back into view.

III

Controls that hide

Drag a blank spot to move (or Alt+drag anywhere), Ctrl+wheel to fine-zoom. A hover hamburger, right-click, or the tray reach the same menu. Nothing on screen until you reach for it.

IV

Built for the wall

Auto-reload every N minutes so a days-long dashboard never bogs down. A local offline-retry page reconnects on a backoff when the host is down. Lock position, always-on-top.

V

Tell them apart

Hue-shift the tray icon, wear the site’s own favicon, or paint a color-matched corner badge — so a wall of vitrines reads at a glance. Each carries its own title.

VI

Kiosk-hardened

Swallow a stray Alt+F4 while letting it ride into a guest VM. Load a self-signed internal host. Per-kiosk password autofill, DPAPI-sealed. Proxmox shell pop-ups open as Vitrine’s own window.

Curator’s note Provenance

It began as a workaround. A wall panel ran on chrome.exe --app=…, and the one thing it could never shake was a taskbar button — clutter on a display that was meant to show only the page.

So Vitrine was built to do the one job properly: hold a single URL behind glass, full frame, and answer to nothing but its own tray icon. openHAB, Proxmox, Grafana, Node-RED, a status wall — each gets its own case, its own session, its own login.

Fittingly, this very page was framed in a Vitrine before anyone saw it.

Acquire the piece

There’s nothing to install.

Vitrine is a portable folder app — no installer, no MSI. Unzip the folder, run vitrine.exe --configure to set up your first kiosk, and it keeps each kiosk’s .json session and WebView2 data beside the exe. Drop it on a USB stick, a Startup folder, or a wall panel. To uninstall, delete the folder.
